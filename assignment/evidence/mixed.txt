TEST 3 — Mixed-version forwarding loop

Command:
sh ./p4cli s2 "table_modify MyIngress.myTunnel_exact MyIngress.myTunnel_forward 2 1"

Output:
Done
Modifying entry 2 for exact match table MyIngress.myTunnel_exact

Command:
h1 python3 send.py 10.65.0.3 "mixed loop" --tunnel 3 --hops 4

First measurement:
sh grep -c "Processing packet received" logs/s1.txt logs/s2.txt

logs/s1.txt:401
logs/s2.txt:396

Five seconds later:
sh sleep 5; grep -c "Processing packet received" logs/s1.txt logs/s2.txt

logs/s1.txt:401
logs/s2.txt:396

Observation:
Both counts remained unchanged after five seconds.
This is consistent with the updated s1 eventually stopping
the loop even though s2 did not enforce the hop limit.

Only the updated switch decremented the hop limit, so
the loop could traverse more switches than when both
switches used the updated program.

The counts include other switch activity and do not
independently establish the exact number of traversals.
